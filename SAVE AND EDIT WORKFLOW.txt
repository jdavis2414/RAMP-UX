Define Users and Location Workflow


Define User Set
- The user will select the "DEFINE USERS AND LOCATIONS" workflow from the environment request workflow screen. 
- The system presents a form with controls for selecting user roles. The user may select all roles that apply. 
- The system will populate table rows with the selected user roles below the user role selection control. The form roles will contain controls for setting the number of each user role expected for the network environment. 
- The user will select the appropriate number for each user role, and select the "CONFIRM" button below. 
- Then the "CONFIRM" button will change to "EDIT" and the user role selections and numbers will remain locked until edited
- The user will select "NEXT" to advance the form to the user locations section

Define User Locations
- When the user has defined numbers for each user role and selected, the system will present form controls for selecting the cities where network users will be located. These controls can be a dropdown with actions to add selected city to a list, or available cities my be displayed as a set of UI "chips" representing all eligible locations  
- Then the user selects all appropriate cities which are added to a list
- Each city entry on the list will display all eligible facilities/campuses. 
- The user will select all eligible cities and then be presented with a list of campuses/buildings and floors for each campus  
- The user will select appropriate campuses/buildings and floors
- The system will present a list of the selected cities and associated campuses/buildings, and floors (do we allow for room numbers as well?)
- The user will review the list and when they have determined that the list is complete, the user will click "NEXT"
- The system will present the user with a summary report detailing selected user roles and associated numbers, as well as all city and facility selections
- The user may return to previous sections of the Define Users and Location form
- When the user has determined that the form is correct, they will select "CONFIRM"
- The system will return the user to the main environment request screen
